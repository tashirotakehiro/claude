# 「気づき」発明フレームワーク

LP構成案の中で最も重要な「気づき（＝教育セクション）」を発明するためのフレームワーク。
ステップ2で「気づき」のアイデアを複数パターン提案するときに、このフレームワークに沿って考える。

---

## 4つの角度

### 角度A：「原因のメカニズム」型
悩みの原因を科学的・身体的に説明し、「だからこの機能が効く」に持っていく。

- **特徴**: 納得感が高い。医学的・生理学的な根拠がある。
- **注意点**: 説明が長くなりがちなので、コラム形式で深掘りすると良い。
- **例**: 「首を温めると皮膚温が上がり、体が放熱しようとして深部体温が下がる。人は深部体温が下がると眠気を感じるため、加温から15分程度で眠気を感じ始める」（ホットPLUS）

### 角度B：「常識の逆転」型
世の中の人が「当たり前」と思っていることを覆す。最もインパクトが強い。

- **特徴**: 「えっ、そうだったの？」という驚きがある。記憶に残りやすい。
- **注意点**: 覆す内容に根拠がないと「眉唾」になる。必ず裏付けを添える。
- **例**: 「枕は1個で十分だと思っていませんか？→ コリ具合は毎日違うから、1個の枕では対応できない」（クワトロ枕）
- **例**: 「姿勢を正すには引っ張ればいいと思っていませんか？→ まず温めてゆるめるのが先」（姿勢サポーター）

### 角度C：「行動と結果の因果」型
ユーザーが普段やっている行動が、実は悩みを悪化させていると気づかせる。

- **特徴**: 自分ごと感が強い。「私がやってたことが原因だったのか」と思わせる。
- **注意点**: 責める口調にならないようにする。「実は…」のニュアンスで。
- **例**: 「電気毛布で温まって気持ちいいけど、実は汗でムレて睡眠の質が下がっている。理想の寝床内気候は温度32〜34℃、湿度50%±5%」（マットレス）

### 角度D：「比較優位」型
既存の解決策（他社製品・従来の方法）が見落としている問題を指摘し、この商品だけが解決できると示す。

- **特徴**: 競合との差別化が明確になる。
- **注意点**: 他社を名指しで批判しない。「一般的な○○は…」の表現で。
- **例**: 「一般的な枕は頭と首を同じ構造で支えている → 本来は頭と首は別々に支えるべき。なぜなら求められる硬さとサポートが違うから」（姿勢リセット）

## 提案フォーマット

気づきを提案するときは、以下のフォーマットで出力する。

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【案1】
【角度】（A〜Dのどれか）
【世の中の認識】世の中の人はこう思っている
【提案する気づき】実はこうである
【納得感の根拠】なぜこの気づきに説得力があるか。科学的・経験的・論理的な裏付け。
【構成案での使い方】LP上でどう展開するか。どのセクションでどう切り出すか。
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 提案時のルール

1. **最低3パターン、できれば5パターン**提案する
2. **異なる角度**から出す（全部が角度Aだけ、などは避ける）
3. **「なるほど！確かに！」と思えるか**を自分でチェックする。眉唾系はNG。
4. 根拠が曖昧なもの、ネットで検索して否定される可能性があるものは出さない
5. ターゲット層の生活や感情に寄り添った表現にする
6. 「気づき」は1つだけ選ぶのではなく、メインの気づき＋サブの気づきとして複数使うこともある

## Web調査の活用

「気づき」の根拠を強化するために、必要に応じて以下を調べる：
- 医学的・科学的なエビデンス（論文、専門家の見解など）
- 競合商品の訴求ポイント（差別化の参考として）
- ターゲット層がよく検索するキーワード（悩みの言語化の参考として）

ただし、調べた情報をそのまま使うのではなく、「この商品の文脈で、ターゲットに刺さる形に翻訳する」こと。

## 選ばれた「気づき」を、LPの結論見出しに変換する

ステップ3に進む前に、選ばれた気づきを**LPの冒頭で言い切る1〜2行**に変換する。
気づきの説明文のままでは、LPの見出しにならない。

| 気づき（分析の言葉） | 結論見出し（LPの言葉） |
|---|---|
| シルクのなめらかさは素材ではなく清潔さで決まる | そのシルクの枕カバー、2日目からは"別の布"です |
| 1枚しかないと清潔な面で寝られる日が週1日しかない | 高いシルクを1枚買うより、清潔なシルクで眠れる日を増やす |

変換のコツ：
- 主語を「読者が今持っているモノ・やっていること」にする
- 「〜で決まる」「〜が大事」ではなく、**読者に何が起きているか**を言い切る
- 変換後の見出しを見て「気になるか？」を自問する。気にならなければ、まだ分析の言葉のまま。
