# CALQS LP構成案の構造パターン

このファイルは、過去6本のLP構成案（マットレス、クワトロ枕、ホットPLUS寝つき、サイドフィット、姿勢サポーター、姿勢リセット）から抽出した共通パターンをまとめたものです。構成案を生成するときの「お手本」として参照してください。

---

## 全体構造（7セクション）

LP構成案は、以下の7つのセクションで構成される。順番は基本的にこの通りだが、商品特性に応じて多少の前後はあり得る。

### 1. FV（ファーストビュー）
- 商品の核心ベネフィットを1〜2行のキャッチコピーで表現
- 「体の悩み × 商品の解決策」を短く凝縮する
- 商品のメイン写真と組み合わせる前提で書く
- 商品名・ブランド名はFVの下に配置

**過去の例：**
- 「疲れた「腰」「背中」「足」を温めて癒す。」（マットレス）
- 「枕難民の解決策 「朝起きたら、首肩が痛い・・・」から、解放される枕！」（クワトロ枕）
- 「たった10分で眠くなってくる。途中で起きても眠れるようになる。」（ホットPLUS）
- 「横向き寝を理想の姿勢に。」（サイドフィット）
- 「ガチガチに固まった首・肩・腰まわりは、まず"ゆるめる"ことから」（姿勢サポーター）
- 「＼寝ている間に／ 首のカーブを支えて、正しい姿勢へ——」（姿勢リセット）

### 2. 悩み共感セクション
- ターゲットの日常的な悩みを「こんな方にオススメ」「こんなお悩みありませんか？」の形で列挙
- 具体的な症状（首こり、腰痛、冷え、いびきなど）と生活シーン（デスクワーク、家事、力仕事）を組み合わせる
- 読んだ人が「私のことだ」と思える具体性が必要

### 3. "気づき"の教育セクション（最重要）
- この構成案の質を決定づける最も重要なセクション
- 「なぜその悩みが起きるのか」のメカニズムを伝え、「だからこの商品が必要」に持っていく
- ユーザーの既存の認知を覆す or 知らなかった事実を提示する
- **流れは必ず「結論 → 理由の箇条書き → 個別解説 → だから◯◯が必要」の型で組む。**
  型・見出しの作り方・わかりやすさの基準は `education-section-patterns.md` に詳細あり。本文を書く前に必ず読む。
- 悩み共感セクションの締めの一文を受けて始める（例：「実は、◯◯を使えばいいというわけではないんです」→「そのXは、2日目からは別物です」）

**過去の「気づき」の例：**
- 「毎日の体のコリ具合は違う → だから枕を毎日変えるべき」（クワトロ枕）
- 「首を温めると深部体温が下がり、脳の入眠スイッチが入る」（ホットPLUS）
- 「電気毛布のムレが睡眠の質を下げている → 理想の寝床内気候がある」（マットレス）
- 「姿勢を正すには、まず温めてゆるめるのが先」（姿勢サポーター）
- 「従来の枕は頭と首を同じ構造で支えている → 本来は別々に支えるべき」（姿勢リセット）

**「気づき」に必要な要素：**
- 納得感がある科学的・医学的・身体的根拠
- 世の中の「常識」との対比（常識の逆転があるとインパクト大）
- 簡潔に説明できること（コラムとして深掘りするのはOK）

### 4. ポイント紹介（3〜6個）
- 「ポイント1」「ポイント2」…の番号付きで差別化ポイントを説明
- **ポイント紹介は「独立した機能紹介」ではなく、教育セクションで提示した問題への"答え合わせ"。**
  - 各ポイントの冒頭1文に `〈「◯◯」への答え〉` を置き、どの問題に答えているかを明示する
  - 並び順は、教育セクションの着地（【だから】）から自然につながる順にする
  - 教育セクションを変更したら、ポイント紹介のリード文・順番・用語も必ず作り直す
- 各ポイントの構造は：
  - ポイント番号 + 小見出し
  - メインの見出しコピー（太字・大きめ／説明ではなく言い切り）
  - 画像（★画像★ └画像の内容説明）
  - 〈「◯◯」への答え〉のリード文
  - 詳細説明テキスト
  - なぜそれが良いのかの補足

**ポイントの分類パターン：**
- 主機能（温め、形状、素材など）
- 快適性（ムレ防止、通気性、肌触りなど）
- 安全性・安心感（電磁波なし、タイマー機能、低温やけど防止など）
- コスト・節約効果（電気代比較など）

### 5. 信頼構築セクション
- メディア掲載実績
- 販売個数（「シリーズ累計○万個突破」）
- 30日間お試しバナー
- おしゃれなシーン写真の並び

### 6. ユーザーの声・レビュー
- 「CASE1」「CASE2」…の形式 or 「○代○性」の属性付き
- 職業・身長体重・生活習慣などの具体的プロフィール付き
- 使い方のバリエーションを見せる（=商品の多面的な価値を伝える）
- ユーザーインタビュー形式（語り口調）で臨場感を出す

### 7. スペック・価格セクション
- 製品仕様（サイズ、素材、温度設定、タイマー、電源、消費電力など）
- 価格（バリエーションがあれば全パターン）
- セット販売がある場合はそれも

## ライティングのトーン・スタイル

### テキストの書き方
- 見出しは短く、太字で目を引く
- **見出しは「主張」であって「説明」ではない。** 「では、なぜ〜でしょうか」のような前振り見出しは使わない
- **見出しだけを縦に読んで話の骨子が伝わるか**を必ず確認する
- **専門用語は本文に置かず、誰もが体験していることに翻訳する。** 数値・エビデンスは括弧書きか注釈に降ろす
- 本文は口語寄りで親しみやすいが、誇大広告にはならない
- `<br>` で改行を入れて、スマホで読みやすいリズムを意識
- 「〜してください」「〜になります」のような丁寧語ベース
- 専門用語は使うが、必ず分かりやすい補足を添える

### 画像指示の書き方
- 「★画像★」で画像が入る位置を示す
- その下に「└」で画像の内容・目的を説明する
- 画像でないと伝わらない部分（構造の断面図、温度分布、ビフォーアフターなど）は明示的に画像指示を入れる

### コラムの使い方
- 「気づき」の深掘りとして、医学的・科学的な説明をコラム形式で入れる
- コラムは長くなっても良いが、本文の流れを止めない位置に配置
- 「コラム：〇〇とは？」のような見出しをつける

## CALQS商品の共通要素

以下の要素はCALQS商品に共通して登場するため、新商品でも該当するものがあれば活用する。

- **遠赤外線温熱（グラフェンシート）**: 電磁波が出ない、遠赤外線で体を芯から温める。ノーベル物理学賞を受賞した素材。一般的な電気毛布のニクロム線との比較。
- **温度設定**: 複数段階（4段階が多い）。各レベルの温度と用途の説明。
- **タイマー機能**: OFFタイマー搭載。つけっぱなし防止。睡眠の質を下げない設計。
- **エアファイバー / エアスルーファイバー**: 通気性の高い素材。
- **高さ調整機能**: 複数パターンの高さ調整が可能。
- **30日間お試し**: 返品保証。
- **節約効果**: エアコンや電気毛布との電気代比較。
