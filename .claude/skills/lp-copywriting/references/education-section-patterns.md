# 教育セクションの型・見出し・読みやすさ

LP構成案で最も差し戻しが起きるのが「気づきの教育セクション」。
このファイルは、**流れの型**・**見出しの作り方**・**読みやすさの基準**を、実際の差し戻し事例つきでまとめたもの。
ステップ3（構成と見出しの確認）とステップ4（本文生成）の前に必ず読む。

---

## 1. 標準の型：結論 → 理由 → 個別解説 → だから

```
【結論】
  言い切りの1〜2行。LP全体で一番大きく見せる。
  ＋ 直後に「誰もが知っている身近な例」を置いて、その場で納得させる。

【理由】
  なぜその結論になるのかを、箇条書きで先に提示する（3つ前後）。
  ここで全体像を見せてから、細部に入る。

【個別解説】
  箇条書きの1つ1つを順番に説明する。各ブロックも「結論見出し → 説明」。

【だから】
  「だから◯◯が必要です」と、商品の必要性に着地する。
  商品名はまだ出さない。次の「商品登場」セクションに渡す。
```

### なぜこの型なのか

- 読者はLPを**読まない。飛ばし見する**。結論を最初に置かないと、そもそも理解されない。
- 理由を先に箇条書きで見せることで、「これから何の話をされるか」が分かり、離脱しにくくなる。
- 「だから」で着地させることで、商品が"売り込み"ではなく"必然"として登場する。

### やってはいけない構成

- ❌ **伏線を張って、順を追って説明していく構成**
  （読者は「今なんの話をされているのか」が分からず離脱する）
- ❌ **主張を5つ並べただけの構成**
  （1つ1つは正しくても、話がつながらない）
- ❌ **ブロックが10個以上ある構成**
  （長いこと自体は悪くないが、意味が取れない話が長いのは致命的）

## 2. 見出しの作り方

### ルール

1. **見出しは「主張」。説明や問いかけの見出しは禁止。**
2. **見出しだけを縦に読んで、話の骨子が伝わること。** 伝わらなければ見出しが弱い。
3. 1〜2行。スマホで2行に収まる長さ。
4. 専門用語を見出しに入れない。
5. 読者の「気になる」を作る。断定・意外性・自分ごと感のいずれかを必ず含める。

### NG / OK 実例（シルクレアLP）

| ❌ NG（差し戻された見出し） | ⭕ OK（採用された見出し） |
|---|---|
| ① まず、その選択は間違っていません | そのシルクの枕カバー、2日目からは"別の布"です |
| ② では、なぜ髪は変わらないのでしょうか | 一晩で、シルクの上は"脂"で覆われるから |
| ③ 買ったばかりのスマホは、なぜ指が滑るのか | ガラスですら、皮脂がつけば引っかかります |
| ⑥ その結果、あなたの髪に起きていたこと | あなたの切れ毛は、眠っている間につくられている |
| ⑨ 答えは、とてもシンプルです。「毎日、洗えばいい」 | 髪のために本当に必要なのは、毎日、洗い立てのシルクで眠ること |

NG側はすべて「これから説明します」という前振りで、**それ自体が何も主張していない**。

## 3. 箇条書き（理由リスト）の作り方

### ルール

- **1つの話を2つに割らない。** 分けるなら、要素・現象の種類で分ける。
- 粒度をそろえる。「原因」と「結果」を同じリストに混ぜない。
- 3つ前後。5つを超えたら統合を検討する。
- 各項目は「短い動詞句 ── 読者が実感している症状」の形にすると強い。

### 実例（シルクレアLP）

❌ 粒度がバラバラだった初稿：
```
1. 一晩で、表面に"膜"ができる
2. その膜は、日ごとに"ベタつき"へ変わる   ← 1と同じ話の後半。理由が2つあるわけではない
3. だから、髪は毎晩こすれている
4. 静電気も起きるようになる
5. そして、雑菌が増えていく
```

⭕ 整理後：**メカニズム（1つ）と、その結果（3つ）に階層を分けた**
```
【なぜ】一晩で、シルクの上は"脂"で覆われるから
  ① 顔と頭皮から出る、皮脂
  ② 髪に塗った、ヘアオイル
  ③ 夜のスキンケアの、油分
  → そして脂は酸化してベタつきに変わる

【その結果】脂で覆われた枕カバーが、髪にすること
  1. 摩擦を増やす  ── 切れ毛・枝毛・パサつき
  2. 帯電させる    ── 朝の広がり・まとまらない
  3. 菌を増やす    ── 頭皮のかゆみ・ニオイ
```

## 4. 難しい話を、わかりやすくする

### ルール

1. **専門用語は本文に置かない。** 必要なら身近な体験に翻訳する。
2. **数値・エビデンスは括弧書きか注釈に降ろす。** 本文の流れを止めない。
3. 1ブロック＝1メッセージ。2つ言いたくなったらブロックを分ける。
4. 説明が3文を超えたら、読者が理解できているか疑う。

### 翻訳の実例

| 言いたいこと | ❌ 難しい書き方 | ⭕ 身近な書き方 |
|---|---|---|
| 表面の汚れで滑りが変わる | 表面自由エネルギーの変化により摩擦係数が上昇します | 新品のスマホは指がスッと滑る。でも数日使うと引っかかる。拭けば、また滑る。素材はずっとガラスのままです |
| 皮脂の酸化で粘着性が増す | 過酸化脂質は粘性を帯び… | 換気扇の油汚れが、時間が経つほどベタベタして落ちにくくなる。あれと同じです |
| 帯電列が近いと静電気が起きにくい | 髪の主成分はケラチン、シルクの主成分はフィブロイン。帯電しやすさの差が小さいため電荷移動が起きにくく… | 本来、髪とシルクは、静電気が起きにくい相性です。どちらも同じタンパク質でできているからです |

### 実例：同じ内容の3稿（シルクレア「静電気」ブロック）

❌ 初稿（専門用語まみれ・長い）：
> 静電気は、こすれ合う2つの物質の「帯電しやすさの差」が大きいほど強く起きます。髪の主成分はケラチン、シルクの主成分はフィブロイン。どちらもタンパク質なので性質が近く、本来は電気が移動しにくい、相性のいい組み合わせなのです。実際の帯電性試験でも、綿 約1,000V／シルク 約1,700V／ウール・ポリエステル 約3,500V。人が静電気を感じるのは約2,000V以上と言われています。

△ 2稿（身近な例を足したが、まだ長い・本題に入るのが遅い）：
> 下敷きで髪をこすると、髪が逆立ちますよね。静電気は、こすれる相手との"相性"で決まります。似ていないもの同士ほど、強く起きる。髪は、タンパク質でできています。そしてシルクも、同じタンパク質。似た者同士だから…

⭕ 採用稿（結論だけ。根拠は括弧に降ろした）：
> 本来、**髪とシルクは、静電気が起きにくい相性**です。
> どちらも同じタンパク質でできているからです。
>
> でも、その表面が**脂とホコリで覆われていたら、静電気は発生しやすくなります。**
>
> そして静電気を帯びた髪は、ふくらむ・浮く・まとまらない。さらに、**ホコリまで吸い寄せます**。
>
> （試験では、ウール・ポリエステル 約3,500Vに対してシルクは約1,700V。人がバチッと感じはじめるのは2,000Vあたりから）

## 5. 教育セクションと、以降のセクションの接続

**教育セクションを変更したら、ポイント紹介以降は必ず作り直す。** 独立したセクションではない。

### 接続ルール

1. ポイント紹介の各項目は、**冒頭1文で「教育セクションのどの問題への答えか」を明示**する。
   例：`〈「帯電させる」への答え〉髪と同じタンパク質の19匁シルクだから…`
2. ポイント紹介の**並び順**は、教育セクションの着地（【だから】）から自然につながる順にする。
   例：「1枚では毎日替えられない」で着地 → 次は枚数（3枚/7枚）の話 → そのあと素材の話
3. 教育セクションで使った**呼び名をそのまま使う**。
   （教育側が「摩擦を増やす／帯電させる／菌を増やす」なら、ポイント側も同じ言葉で受ける）
4. レビューの見出しは、教育セクションで説明した症状の**解決形**にする。
   例：「朝の広がりが、明らかに減りました」「切れ毛を探す時間が、なくなりました」
