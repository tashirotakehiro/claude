# 主力商品カタログ

分かること: 自社企画商品の骨格（ID・正式名・ブランド／シリーズ・本店 handle・参考価格・トライアル対象・状態・カルテの所在）。
分からないこと: 現在価格・在庫・販売数・原価（→ sources.md の一次ソース）。旧 LP・サテライト LP の handle 一覧（→ 各カルテ「LP一覧」）。

## 凡例
- **ID**: 製品コード。正はヘイマス（商品情報管理）の product_group。ヘイマス未照合のため、ここでは Shopify の商品名に付く型番表記【 】を仮 ID とし「(仮)」を付ける。型番の無い商品は本店 handle を仮 ID にする
- **帰属基準**: calqs-sleep.com に商品ページがある＝CALQS（カルテは calqs-others.md）。無い自社企画品＝サバキューストア（survaq-store-products.md）。境界品の最終判断は代表（確認待ち）
- **掲載範囲**: 自社企画の主力のみ。仕入・セレクト品、旧 LP・サテライト LP・特例対応（コントローラー単品等）・ギフトバッグは載せない。**主力の選定は代表確認待ち**（現状は Shopify 上で現行販売中の自社企画品を候補として全掲載）
- **参考価格**: Shopify の price（税込）、バリアント最小値〜最大値。2026-09 確認。正は Shopify／ヘイマス。会話・下書きでは「参考」と付けて使い、広告・LP・CS に載せる価格は一次ソースで再確認する。通常価格（比較対照価格）は書かない
- **トライアル**: 2026-09-11 時点で CALQS 公式のコレクション「30日返品キャンペーン対象商品一覧」に入っている＝対象（別の根拠のものは括弧で明示）。対象一覧は3ソースで一致しない。制度の中身は brands/calqs.md「トライアル制度」
- **状態**: 現行／終売／期間限定（販売期間）。「季節」は使わない
