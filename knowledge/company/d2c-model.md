# D2C 事業モデルと企画時の仮定値

株式会社サバキューの主力事業は、自社企画商品を SNS 広告から直販する D2C EC。このファイルは事業モデルの「仕組み」と、商品企画・収益試算で使う「仮定値」の唯一の置き場。スキル運用ルール（価格の扱い・市場実測シグナル・共通キル基準）は `.claude/skills/_shared/business-model.md` が正。

## 仕組み
- SNS 広告（Instagram／TikTok／Facebook 等のフィード・リール広告）→ LP → 購入、の直販モデル（出典: _shared/business-model.md、2026-09 確認）
- 突然 SNS 広告で知った商品を、決して安くない価格で衝動購入してもらうモデル。広告で立ち止まってもらう「引き」が最重要で、LP で悩みに深く刺さる説明をして購入決断を促す（出典: 同）
- 販売の場は自社 Shopify 2店舗（サバキューストア・CALQS 公式）と、楽天・Amazon・Yahoo! のモール。詳細は brands/*.md と sources.md
- 日常的・慢性的な深い悩み（肩こり、睡眠、ダイエット、美容、腰痛、姿勢 等）を解決するユニークな商品を企画・販売する（出典: 同）

## 企画時の仮定値（机上の定数）
商品企画・収益試算で共通に使う値。**机上の定数であり会社の実績値ではない**。試算に使うときは `_shared/business-model.md`「市場実測シグナル」（同カテゴリ広告の継続配信期間・競合レビュー増加速度 等）で裏を取り、裏が無ければ「未検証」と明記する。値を変えるときはこの表だけを直す（`[方針]` タグ）。

| 項目 | 仮定値 | 用途・注記 |
|---|---|---|
| 商品単価帯 | ¥10,000〜¥20,000 | 企画対象の価格帯。**販売価格そのものは人が決める**（`_shared/business-model.md`「価格の扱い」） |
| 原価率 | 約30% | 製造・仕入れ（倉庫入荷まで）の成立判定に使う |
| 広告費比率 | 約40% | 売上に対する広告費 |
| その他経費 | 約10% | 物流・決済手数料・人件費等 |
| 営業利益率 | 約20% | 上記3項目の残り |
| CPC 目安 | Instagram／Facebook ¥50〜150、TikTok ¥30〜100 | 悲観シナリオは上限側を使う |
| CVR 目安 | 1〜3%（D2C EC 平均） | 悲観シナリオは 1% |
| 年商目標（商品単位） | 3,000万円以上 | 1商品あたり年間で見込みたい売上 |
| ROAS の目安 | 250% 以上を「現実的」、200% を最低ライン | 収益試算アプリ（agents/）の損益分岐の目安。判定は人が行う |

## 収益式
- ROAS ＝ 売上 ÷ 広告費
- 売上 ＝ アクセス数 × CVR × 客単価
- アクセス数 ＝ 広告費 ÷ CPC
- 損益分岐 ROAS ＝ 原価＋広告費＋経費をカバーする最低 ROAS。悲観シナリオ（CPC 上限 × CVR 1%）で CPA が粗利を超えるなら No-Go の強い材料（判定は人）

## このモデルで売れる商品の絶対条件
1. **商品＝広告クリエイティブ**: スクロールを止めるフックと「納得の理屈」が商品自体に内蔵されていること。LP のファーストビューが書けない商品は、企画として存在しないのと同じ
2. **深い悩みの解決**: 日常的・慢性的な悩みにアプローチする
3. **独自性**: Amazon／楽天の ¥3,000 類似品に流れない理由があること（「これは Amazon では買えない」と言える）
4. **3秒の映像化**: リール／TikTok で効果・使用感が3秒で伝わること

（出典: _shared/business-model.md「このモデルで売れる商品の絶対条件」、2026-09 確認。旧 shared-context.js の「成功する商品の条件」4項目＝深い悩みの解決／独自性／強いベネフィット／LP での説得力 は、上記に統合）
