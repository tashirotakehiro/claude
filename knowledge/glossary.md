## 商品の識別子
| 用語 | 意味 |
|---|---|
| 製品コード | ヘイマス product_group の型番プレフィックス。Shopify の商品名【 】内の型番表記と一致することが多い（例 PH01＝ホッとする枕PLUS、PDP01＝ダブル枕PLUS、DP01＝ダブル枕ベーシック、NHP01＝ホッとする枕ベーシック、QTP01＝クワトロ枕、HPG／HPSF／HPLF＝グランデ／サイドフィット／ローフラット、WC01＝首と肩を癒す枕カバー、HLP01／HFP01／HBS01／HEM2601＝腰枕／足枕／姿勢サポーター／アイマスク）。ヘイマス未照合のものは catalog で「(仮)」 |
| 型番の接尾辞（推定・未確認） | -SL＝2層タイプ、-OLD＝旧 LP、-REC＝レコメンド専用ページ、-Y／-YDA＝Yahoo!／YDA 流入用、-LINE／-LH＝LINE 流入用、-COOL＝ヘッドクール系、-NP＝寝つき訴求。**社内の命名規則は未確認**（ヘイマスで確認後に確定） |
| handle | Shopify の商品 URL スラッグ（/products/<handle>）。CALQS 公式とサバキューストアで原則同じだが、一部ハイフン有無や日本語 handle が異なる → catalog |
| 本店 LP | CALQS 公式（または各ストア）の正規の商品ページ |
| サテライト LP／サテライトページ | 広告流入用に別 handle で作る商品ページ（`satellite-*`）。訴求別・媒体別・日付付きの派生がある。作り方の正は Notion「サテライトページの作成・管理」→ brands/calqs.md「LP 体系」 |
| `_old`／`_yahoo`／`_rec`／`_cp`／`_cotton` | handle の派生種別。旧 LP／Yahoo! 流入用／レコメンド専用／キャンペーン用／コットンのみ版（推定。Shopify 観察より） |
| 期間限定フォーム（セールフォーム） | Shopify 商品のカートフォームを通常時とセール時で日時で切り替える仕組み。設定の正は calqs-sale-form スキル → brands/calqs.md「セール制御の所在」 |
| コントローラー単品 | 温熱枕の電源コントローラーだけを【特例対応】として販売する商品。CS 対応用 |
