# 文章・広告の自社ルール

LP・広告・CS 文面で共通に守ること。トーンの「重視する点」は代表・マーケ確認後に追記する。

## 共通

- 商品名は products/catalog.md の正式名（CALQS 公式の Shopify title）に合わせる。揺れの観察: ホッとする枕PLUS／首と肩がホッとする枕プラス／ホットPLUS、ダブル枕PLUS／ダブル枕プラス、アイトゥカム2／EYE to CAM2

### 薬機法・景表法
- 「治る」「改善する」を避け、「〜と言われています」「〜が期待できます」を使う。他社を名指しで批判しない（「一般的な○○は…」）（出典: lp-copywriting SKILL・references、2026-09 確認）
- 仕様・効果・技術の主張は出典付きの事実だけを使う（下表）。出典が無い主張は LP・広告・CS に載せない
- 通常価格（比較対照価格）の表示ルール、審査で問題になった表現は確認後に追記（ヒアリング E-13）
- LP 制作で「仮レビュー」を作る工程がある（lp-copywriting）。仮レビューは実レビューとして公開しない

### トーン（共通則。ブランド別の希望はヒアリング E-11）
- 見出しは短く太字。本文は口語寄りで親しみやすいが誇大広告にしない。丁寧語ベース（「〜してください」「〜になります」）。専門用語には補足を添える（出典: lp-copywriting references、2026-09 確認）
- LP 構成の型は7セクション（FV／悩み共感／気づきの教育／ポイント紹介／信頼構築／ユーザーの声／スペック・価格）。正は lp-copywriting スキル

### 広告の命名・計測（正は Notion「広告媒体設定(サバキュー独自の設定/ルール)」）
- キャンペーン名・広告セット名に「記号」「空白」を使わない（例外: 【】‐_）。名称の先頭に Shopify のプロダクト ID を付ける（売上・利益グラフとの連携用）。名称は途中変更しない（初期名で連携される）。utm_campaign と名称は一言一句同じにする（出典: Notion、2026-09 確認）
- 予算・目標 ROAS の変更幅は原則20%以内。1キャンペーン／広告セットに最低3個、基本5〜10個のクリエイティブを入れて出稿（出典: 同）
- Meta: 広告セット単位で日予算とプロダクト ID。リンク先は原則サテライト LP（ドメイン BAN リスク回避）。URL パラメータ `utm_source=Facebook&utm_medium=Facebook_Feed&utm_campaign={{adset.name}}&utm_content={{ad.name}}`（出典: 同）
- Google／Yahoo!: キャンペーン単位。トラッキングテンプレート `{lpurl}?utm_source={_utmsource}&utm_medium={_utmmedium}&utm_campaign={_utmcampaign}`。LINE／SmartNews／Pinterest／X／TikTok は URL Builder で `utm_source=<媒体>&utm_medium=cpc&utm_campaign=[名称]` を手動付与（出典: 同「広告媒体別ルール」）
- Meta 入稿の慣習: パターン名は英字＋数字（A1〜F2）、adlabel は `img_feed_<パターン>`／`img_story_<パターン>`／`body_`／`title_`／`desc_`／`url_`、画像はフィード 1080×1080・ストーリー/リール 1080×1920、広告は一時停止で作成し人が有効化（出典: meta-ads-creator スキル、2026-09 確認）
- 広告セット名の例: `<プロダクトID>_ダブル枕PLUS_20251024_30歳以上`（出典: Notion、2026-09 確認）
